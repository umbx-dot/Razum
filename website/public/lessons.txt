=== lesson welcome | Getting started | Hello, razum
razum is a small programming language that looks like C. You write a `.rz` file, and the compiler **rzc** translates it into a native program on Windows or Linux. The learning site runs on Windows and builds an `.exe` you can run on its own. In between, rzc writes plain assembly, so you can see what the processor will do.

On this page, the compiler runs on your own computer: press **Run** (or Ctrl+Enter) and the program on the right is compiled and started.

```c
import stdio;

int main() {
    print("Hello, world!");
    return 0;
}
```

| Line | Meaning |
|---|---|
| `import stdio;` | use the standard input/output library, which has `print` |
| `int main() {` | every program starts in the function `main` |
| `print("...");` | write text and end the line; text in double quotes is a *string* |
| `return 0;` | end the program; 0 means "no problems" |

Every instruction ends with a semicolon `;`, and braces `{ }` group lines that belong together.
--- starter
import stdio;

int main() {
    print("Hello, world!");
    return 0;
}
--- task

--- expect

I am learning.
--- hint
Use two `print` calls, one per line.
--- solution

    print("Hello, razum!");
    print("I am learning.");
    return 0;
}

=== lesson output | Getting started | Output on one line
Use `print(value)` to write a value and end the line. It reads the type for you, so numbers, text, and results like `print(1000 * 1000)` work the same way.

Use `printf(value)` to keep writing on the current line. It also reads the type for you. In text, `%n` starts a new line and `%%` writes one percent sign.

```c
printf("Apples: ");
printf(12);
printf(" total%n");
printf("Progress: 50%%%n");
```

This writes `Apples: 12 total` and `Progress: 50%` on separate lines. Each call prints one value. Sequences such as `%d` print as ordinary text.

The `write_*` functions are also available when you want to choose how a value is written. For example, `write_long(42)` writes a whole number, `write_string("%n")` writes those two characters literally, and `print_line()` ends the line.
--- starter
import stdio;

int main() {
    printf("Apples: ");
    printf(12);
    printf(" total%n");
    return 0;
}

=== lesson variables | Getting started | Variables and types
A **variable** is a named place that holds a value. Its **type** says what kind of value:

| Type | Holds | Example |
|---|---|---|
| `int` | whole numbers up to about 2 billion | `int count = 10;` |
| `long` | much larger whole numbers | `long stars = 100000000000;` |
| `double` | numbers with a fraction | `double price = 0.25;` |
| `bool` | `true` or `false` | `bool done = false;` |
| `char` | one character | `char grade = "A";` |
| `string` | text | `string name = "Ada";` |

`count = count + 1;` means "compute the right side, then store it on the left". A variable keeps its type forever: `int count = 2.5;` is an error, because 2.5 does not fit a whole number. razum checks this before the program runs.
--- starter
import stdio;

int main() {
    int count = 10;
    count = count + 1;
    print(count);
    string name = "Ada";
    print(name);
    return 0;
}

=== lesson arithmetic | Getting started | Arithmetic
| Operator | Meaning | `7 ? 2` with whole numbers |
|---|---|---|
| `+` `-` `*` | add, subtract, multiply | 9, 5, 14 |
| `/` | divide | **3** (the fraction is cut off) |
| `%` | remainder | 1 |

With a `double` on either side, `/` keeps the fraction: `7 / 2.0` is `3.5`. A cast converts on purpose: `(double)7 / 2` is `3.5`, `(int)3.9` is `3`.

Shortcuts: `x += 5;` adds 5, `x++;` adds 1, `x--;` takes 1 away.

```c
int total = 135;
print(total / 60);    // 2  (hours)
print(total % 60);    // 15 (minutes left over)
```

=== lesson decisions | Control flow | Decisions with if
`if` runs statements only when a condition is true. The checks run from the top, the first true one wins, and `else` catches the rest.

```c
if (score >= 90) {
    print("excellent");
} else if (score >= 50) {
    print("passed");
} else {
    print("not yet");
}
```

| Comparison | True when |
|---|---|
| `a == b`, `a != b` | equal, not equal (two `=`!) |
| `a < b`, `a <= b`, `a > b`, `a >= b` | less, less or equal, ... |
| `x && y`, `x || y`, `!x` | and, or, not |
--- starter
import stdio;

int main() {
    int score = read_int();
    if (score >= 50) {
        print("passed");
    } else {
        print("not yet");

    return 0;
}

=== lesson switch | Control flow | Choosing with switch
When one value is compared with many fixed values, `switch` is clearer than a chain of `if`s. Only the matching case runs; razum never "falls through" into the next case. `default` runs when nothing matches, and one case may list several values.

```c
switch (month) {
    case 12, 1, 2:
        print("winter");
    case 6, 7, 8:
        print("summer");
    default:
        print("in between");
}
```

import stdio;

int main() {

}

=== lesson while | Control flow | Loops with while
`while` repeats its block as long as the condition is true. Something inside the loop must eventually make it false, or the program runs forever (here it would be stopped after 5 seconds).

```c
int countdown = 3;
while (countdown > 0) {
    print(countdown);
    countdown--;
}
print("Liftoff!");
```

`break` leaves a loop at once; `continue` skips to the next round.
--- starter
import stdio;

int main() {
    int countdown = 3;
    while (countdown > 0) {
        print(countdown);
        countdown--;

}

=== lesson functions | Functions and data | Functions
A **function** is a named piece of program you can use again and again. It takes **parameters** and can **return** a value; `void` means it returns nothing. Functions can be written in any order.

--- task
Write `bool is_prime(int n)` (a prime has exactly two divisors, 1 and itself; 1 is not prime) and print all primes below 30 on one line, separated by spaces.
--- requires bool\s+is_prime\s*\( :: Write a function bool is_prime(int n).
--- test
--- expect

--- hint

--- solution
import stdio;

bool is_prime(int n) {
    if (n < 2) {
        return false;
    }
    for (int divisor = 2; divisor * divisor <= n; divisor++) {
        if (n % divisor == 0) {
            return false;
        }
    }
    return true;
}

int main() {
    for (int n = 2; n < 30; n++) {
        if (is_prime(n)) {
            write_long(n);
            write_char(' ');
        }
    }
    print_line();
    return 0;
}

=== lesson recursion | Functions and data | Recursion
A function may call itself. This works when every call gets closer to a case that needs no further call:

```c
long factorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}
```

`factorial(4)` is `4 * factorial(3)` = `4 * 3 * factorial(2)` = `4 * 3 * 2 * 1` = 24.
--- starter
import stdio;

long factorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

int main() {
    print(factorial(10));
    return 0;
}

=== lesson arrays | Functions and data | Arrays
An **array** holds a fixed number of values of one type. Each element has an **index**, starting at **0**; `.length` is how many there are.

```c
int scores[5] = {72, 95, 61, 88, 79};
print(scores[0]);         // 72, the first
print(scores.length);     // 5
scores[2] = 65;
for (int i = 0; i < scores.length; i++) {
    print(scores[i]);
}
```

The first and last elements have names of their own: `scores.first` and `scores.last` (the same as `scores[0]` and `scores[scores.length - 1]`, and you can assign to them). Loop with `i < scores.length`, never `<=`, or you read past the end.
--- starter
import stdio;

int main() {
    int scores[5] = {72, 95, 61, 88, 79};
    int total = 0;
    for (int i = 0; i < scores.length; i++) {
        total += scores[i];
    }
    print(total);
    return 0;
}
--- task
Given `int scores[8] = {72, 95, 61, 88, 79, 54, 99, 67};`, print the largest score, the smallest score, and the average (as a `double`), each on its own line.
--- requires \.length :: Loop with scores.length.
--- test
--- expect
99
54
76.875
--- hint
Start `best` and `worst` at `scores[0]` and compare with each element. The average is `(double)total / scores.length`.
--- solution
import stdio;

int main() {
    int scores[8] = {72, 95, 61, 88, 79, 54, 99, 67};
    int best = scores[0];
    int worst = scores[0];
    long total = 0;
    for (int i = 0; i < scores.length; i++) {
        if (scores[i] > best) {
            best = scores[i];
        }
        if (scores[i] < worst) {
            worst = scores[i];
        }
        total += scores[i];
    }
    print(best);
    print(worst);
    print((double)total / scores.length);
    return 0;
}

=== lesson arraytools | Functions and data | Sorting and array tools
Writing a loop for the largest value is good practice, but you do not have to do it every time. With `import array;` every array of numbers or characters gets **methods**, written after a dot:

```c
import stdio;
import array;

int main() {
    int scores[6] = {72, 95, 61, 88, 79, 95};
    scores.sort();                  // 61 72 79 88 95 95
    scores.sort_descending();       // 95 95 88 79 72 61
    print(scores.first);            // 95, the best
    print(scores.last);             // 61, the worst
    print(scores.sum());            // 490
    print(scores.max());            // 95
    print(scores.contains(88));     // true
    print(scores.index_of(79));     // 3, or -1 if it is not there
    scores.reverse();               // 61 72 79 88 95 95
    scores.fill(0);                 // every element becomes 0
    return 0;
}
```

| Method | Does |
|---|---|
| `sort()`, `sort_descending()` | smallest first, largest first |
| `reverse()` | turns the order around |
| `min()`, `max()`, `sum()` | smallest, largest, total |
| `contains(x)`, `index_of(x)` | is `x` there, and where |
| `fill(x)` | sets every element to `x` |

`sort` is fast: for big arrays it is a radix sort, which puts numbers in order byte by byte instead of comparing them, and on five million numbers it beats C++'s `std::sort`. It works for every number type and for `char`, so `letters.sort()` puts letters in alphabetical order.
--- starter
import stdio;
import array;

int main() {
    int points[8] = {12, 40, 7, 33, 40, 18, 25, 3};
    print(points.max());
    return 0;
}

=== lesson structs | Functions and data | Structs
A **struct** groups values that belong together into a new type. Each part is a **field**.

```c
struct Point {
```

A struct given to a function is the caller's struct, not a copy, so the function can change it.

=== lesson enums | Functions and data | Constants and enums
`const` names a value that never changes; razum computes it while compiling, so it costs nothing at run time, and it can size arrays:

```c
const int SIZE = 3;
int board[SIZE * SIZE];
```

An `enum` is a type with a fixed set of named values, written with the enum's name in front:

```c
enum Direction { NORTH, EAST, SOUTH, WEST }

Direction facing = Direction.NORTH;
if (facing == Direction.NORTH) {
    print("up");
}
```

`Direction facing = 2;` is an error: 2 is not a direction. `(Direction)2` converts on purpose.
--- starter
import stdio;

enum Direction { NORTH, EAST, SOUTH, WEST }

int main() {
    Direction facing = Direction.EAST;
    switch (facing) {
        case Direction.NORTH:
            print("up");
        case Direction.EAST:
            print("right");
        default:
            print("somewhere else");
    }
    return 0;
}

=== lesson pointers | Going deeper | Pointers and the heap
A **pointer** holds the address of a value. `&x` is the address of `x`; `*p` is the value at an address.

```c
void double_it(int *value) {
    *value = *value * 2;
}

int x = 21;
double_it(&x);    // x is now 42
```

`new` asks for memory while the program runs, so its size can come from the user; `free` gives it back:

```c
long *squares = new long[count];
squares[0] = 0;
free(squares);
```
--- starter
import stdio;

void double_it(int *value) {
    *value = *value * 2;
}

int main() {
    int x = 21;
    double_it(&x);
    print(x);
    return 0;
}
--- input
5
--- task
Write `void swap(int *a, int *b)` and use it so `int x = 3; int y = 9;` prints `9 3`. Then read n, make an array of n `long`s with `new`, fill it with 1², 2², ..., n², print their sum, and `free` it.
--- requires void\s+swap\s*\(\s*int\s*\*\s*\w+\s*,\s*int\s*\* :: Write void swap(int *a, int *b).
--- requires new\s+long\s*\[ :: Use new long[n].
--- requires free\s*\( :: Free the array.
--- test
5
--- expect
9 3
55
--- test
3
--- expect
9 3
14
--- solution
import stdio;

void swap(int *a, int *b) {
    int keep = *a;
    *a = *b;
    *b = keep;
}

int main() {
    int x = 3;
    int y = 9;
    swap(&x, &y);
    write_long(x);
    write_char(' ');
    print(y);

    long sum = 0;

        squares[i] = (long)(i + 1) * (i + 1);
        sum += squares[i];
    }
    print(sum);
    free(squares);
    return 0;
}

=== lesson functionvalues | Going deeper | Functions as values
A function can be stored in a variable and handed to another function. `fn(long) -> long` is the type of "a function that takes a long and returns a long":

```c
long twice(long x) {
    return x * 2;
}

fn(long) -> long change = twice;
print(change(21));    // 42
```

Passing functions around is how you write code that decides *what* to do later: a sort that takes a comparison, a button that takes what to do when clicked.
--- starter
import stdio;

long twice(long x) {
    return x * 2;
}

long apply_twice(fn(long) -> long change, long value) {
    return change(change(value));
}

int main() {
    print(apply_twice(twice, 5));
    return 0;
}
--- task
Write `void apply(long values[], fn(long) -> long change)` that replaces every element with `change(element)`. Start with `{1, 2, 3, 4}`, apply a doubling function and print the values on one line, then apply a squaring function and print them again: `2 4 6 8` and `4 16 36 64`.
--- requires fn\s*\(\s*long\s*\)\s*->\s*long :: Take a fn(long) -> long parameter.
--- test
--- expect
2 4 6 8
4 16 36 64
--- solution
import stdio;

long double_it(long x) {
    return x * 2;
}

long square(long x) {
    return x * x;
}

void apply(long values[], fn(long) -> long change) {

        values[i] = change(values[i]);
    }

=== lesson threads | Going deeper | Threads and channels
Modern computers have many cores. `import threads;` runs functions on real threads at the same time, and **channels** let them hand values to each other safely, as in Go:

```c
Channel *results = channel_new(16);

void work(long part) {
    channel_send(results, part * part);
}

long worker = thread_start(work, 7);
long value = 0;
channel_receive(results, &value);   // waits for the worker: 49
thread_join(worker);
```

A thread function takes one `long` and returns nothing.
--- starter
import stdio;
import threads;

Channel *results;

void work(long part) {
    channel_send(results, part * part);
}

int main() {
    results = channel_new(16);
    long worker = thread_start(work, 7);
    long value = 0;
    channel_receive(results, &value);
    print(value);
    thread_join(worker);
    return 0;
}
--- task
Add up 1 to 1,000,000 with **four** threads: thread `part` (0 to 3) sums its quarter (`part * 250000 + 1` to `(part + 1) * 250000`) and sends the result through a channel. `main` receives the four results and prints the total, `500000500000`.
--- requires thread_start :: Start threads with thread_start.
--- requires channel_send :: Send results through a channel.
--- test
--- expect
500000500000
--- solution
import stdio;
import threads;

Channel *results;

void sum_quarter(long part) {
    long total = 0;
    for (long n = part * 250000 + 1; n <= (part + 1) * 250000; n++) {
        total += n;
    }
    channel_send(results, total);
}

int main() {
    results = channel_new(4);
    long workers[4];
    for (int part = 0; part < 4; part++) {
        workers[part] = thread_start(sum_quarter, part);
    }
    long total = 0;
    long value = 0;
    for (int i = 0; i < 4; i++) {
        channel_receive(results, &value);
        total += value;
    }
    for (int part = 0; part < 4; part++) {
        thread_join(workers[part]);
    }
    print(total);
    return 0;
}

=== lesson assembly | Going deeper | A look at the machine
razum lets you write processor instructions directly in an `asm { }` block. A variable `x` is at `[rsp + .x]`, and a function's result goes in `rax`:

```c
long add_one(long value) {
    asm {
        mov rax, qword [rsp + .value]
        add rax, 1
    }
}
```

This is how the libraries reach instructions that no language has a word for, like counting bits.

    }

=== lesson json | Useful libraries | Read and write JSON
JSON is a text format for exchanging structured data. `{"count":6}` is a JSON **object** with a key called `count` and a numeric value. In a razum string, escape the inner quotes with a backslash: `"{\"count\":6}"`.

`json_parse` takes the source, its length in bytes, and an array of `JsonToken` values. A token describes a range in the original text. Keep the text available while using the tokens. A negative parse result means an error, and token `0` is the root after a successful parse.

| To do this | Use |
|---|---|
| Find a named value in an object | `json_member` returns its token index, or `-1` if it is missing |
| Read a signed whole number | `json_read_long` takes a token and the address of a `long`, like `&count` |
| Write an object | Use `JSON_OBJECT`, then `JSON_KEY` followed by its value, and finally `JSON_END` |
| Finish the output | `json_writer_finish` returns its length or a negative error |

The writer inserts punctuation and escapes text. The output buffer must have room for the JSON and its terminating zero. Each write returns `0` on success.
--- starter
import json;
import stdio;
import text;

bool read_count(string source, long *count) {
    JsonToken tokens[32];
    int used = json_parse(source, length(source), tokens, tokens.length);
    if (used < 0) {
        return false;
    }
    int field = json_member(source, tokens, used, 0, "count");
    return field >= 0 && json_read_long(source, tokens[field], count);
}

int main() {
    char source[256];
    long count;
    if (!read_input(source) || !read_count(source, &count)) {
        print("Invalid count");
        return 0;
    }
    print(count);
    return 0;
}

--- task

import json;
import stdio;
import text;

bool read_count(string source, long *count) {
    JsonToken tokens[32];
    int used = json_parse(source, length(source), tokens, tokens.length);
    if (used < 0) {
        return false;
    }
    int field = json_member(source, tokens, used, 0, "count");
    return field >= 0 && json_read_long(source, tokens[field], count);
}

int main() {
    char source[256];
    long count;
    if (!read_input(source) || !read_count(source, &count)) {
        print("Invalid count");
        return 0;
    }
    char result[64];
    JsonOutput output;
    json_writer_init(&output, result, result.length);
    if (json_write_event(&output, JSON_OBJECT, "", 0) != 0 ||
        json_write_event(&output, JSON_KEY, "double", 6) != 0 ||
        json_write_long(&output, count * 2) != 0 ||
        json_write_event(&output, JSON_END, "", 0) != 0 ||
        json_writer_finish(&output) < 0) {
        return 1;
    }
    print(result);
    return 0;
}

=== lesson time | Useful libraries | Clocks and UTC timestamps
Use a monotonic clock for measuring an interval and the system clock for printing a date.

| Function | Result |
|---|---|
| `time_monotonic_ns()` | Nanoseconds since an unspecified starting point. Subtract an earlier reading from a later one to get an elapsed time. |
| `time_unix_us()` | UTC time in microseconds since midnight on 1 January 1970. System clock adjustments can change this reading. |
| `time_format_utc(microseconds, target)` | Writes a UTC timestamp with six fractional digits and a trailing `Z`. The buffer needs at least 28 bytes, including its terminating zero. |

One second is `1000000` microseconds and `1000000000` nanoseconds. For example, Unix time `0` formats as `1970-01-01T00:00:00.000000Z`. Negative Unix times represent dates before 1970.
